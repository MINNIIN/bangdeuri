# 방들이

> 내 방은 친구들이 채워줘.

내 미니미를 직접 만들고 방 링크를 보내면, 친구들이 들어와 같이 돌아다니고 수다 떨고 가구를 쓰고 선물을 놓고 가는 미니룸 서비스입니다.
싸이월드 미니룸 + 방명록 + 실시간 놀이터. 방 주인은 회원(카카오 · 구글 · 이메일), 놀러 오는 친구는 가입 없이 닉네임만.

- 기획·설계 문서: [docs/design.md](docs/design.md)
- 무료 배포 가이드: [docs/deploy.md](docs/deploy.md)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 회원 | 카카오 · 구글 · 이메일 가입. 처음에 닉네임을 정하고 내 미니미를 직접 만든다 |
| 내 미니미 만들기 | 머리 5종 · 눈 5종 · 상의 3종 · 하의 4종 · 모자/장식 6종 + 머리 · 피부 · 옷 · 모자 색. 대시보드에서 언제든 다시 꾸미기 |
| 대시보드 | 내 미니미, 내 방 목록(없는 동안 쌓인 대화 수), 방 만들기, 알림 설정, 로그아웃 |
| 방 만들기 | 방 3종(핑크 하트방 · 원룸 자취방 · 밤하늘 다락방), 방 이름과 오늘의 한마디. 방 주인 미니미는 내가 만든 미니미 |
| 놀러 가기 | 손님은 링크를 누르고 닉네임만 치면 들어간다(모습은 주사위로 섞기). 회원은 내 닉네임으로 갈지, 익명("수상한 고구마" + 복면 미니미)으로 갈지 고른다 |
| 같이 놀기 (실시간) | 같은 방 사람들의 미니미가 이름표를 달고 보이고, 걷기 · 가구 쓰기 · 옷 갈아입기 · 스탠드 · TV 채널이 서로 보인다. 방 주인이 없으면 주인 미니미가 혼자 집에서 논다. 한 방 최대 10명 |
| 수다방 (채팅) | 지금 있는 사람 목록, 말풍선이 미니미 머리 위에 뜬다. 기록이 남아서 방 주인이 나중에 "없는 동안 새 대화"를 본다. 방마다 최근 500개 · 30일 |
| 알림 (PWA 푸시) | 방 주인이 켜 두면 "OO님이 들어왔어요", "OO님이 라면을 두고 갔어요". 홈 화면에 추가해서 앱처럼 쓰기 |
| 방 주인 관리 | 채팅 · 아이템 지우기, 손님 내보내기(10분), 링크가 퍼지면 새 링크 만들기 |
| 아이템 놓기 | 친구가 링크로 들어와 아이템 42종(가구·가전·소품·먹을거·킹받는거) 중 하나를 골라 방 바닥에 놓고 닉네임·한마디를 남김. 놓자마자 방에 보임. 방마다 1개, 방 하나에 최대 60개 |
| 방명록 | 아이템을 누르면 그 위에 말풍선. "방명록 보기"에서 5개씩 페이지로 넘겨 보기. 방 주인은 아이템 치우기·한마디 수정, "직접 아이템 놓아 보기"로 친구처럼 놓아 보기 |
| 투룸 집 | 거실 · 안방 · 작은방 · 주방 · 화장실. 낮은 칸막이벽이라 안이 들여다보이고, 기본 가구 17개(침대·소파·TV·변기·욕조·싱크대 …)가 처음부터 있음 |
| 둘러보기 | 끌어서 이동, 마우스 휠·두 손가락 벌리기로 확대·축소, PC 우클릭 드래그·두 손가락 비틀기로 ±30° 회전, 방 이름 칩으로 그 방으로 이동 |
| 가구 쓰기 | 가구를 누르면 미니미가 벽을 돌아 걸어가서 사용: TV 보기(채널 5개, 다시 누르면 채널 변경), 침대에 눕기(불 꺼짐·Zzz), 변기에 앉기(일어나면 물 내림), 욕조 목욕, 옷장에서 옷 갈아입기, 냉장고·싱크대·세탁기 등. 친구가 놓은 아이템 42종도 말풍선의 버튼으로 사용(쓰다듬기·먹기·디스코 파티·바선생 보고 도망가기 …). 친구도 똑같이 할 수 있음 |
| 방 꾸미기 (방 주인) | 거실 기준으로 벽지 무늬 9종·색 12색(왼쪽/오른쪽/양쪽), 벽에 도트 그림 그리기(12색·지우개·되돌리기), 벽 장식 10종 붙이고 끌어 옮기기(벽마다 5개), 바닥 무늬 6종·색 12색 |
| 미니미 이동 | 빈 바닥을 탭/클릭하거나 PC에서 우클릭(짧게)하면 그 자리에 작은 링이 오므라들며 표시되고 미니미가 걸어감 (드래그는 둘러보기, 살짝 탭은 이동이라 겹치지 않음) |
| 방 삭제 | 방 주인 화면 맨 아래 '방 삭제하기' → 한 번 더 확인하면 방과 아이템·방명록·채팅이 모두 지워짐 |
| 3D 동네 | 방은 3D 디오라마. 방 밖으로 나가면 골목이 있고, 서로 놀러 간 적 있는 친구들 집(최대 9채)이 마당·울타리·대문·우편함과 함께 늘어서 있다. 같이 접속한 사람들은 골목·친구 집을 함께 돌아다닌다 (같은 곳에 있는 사람만 보인다). 집 문을 누르면 들어가고, 현관 매트를 누르면 나온다. 주인이 없는 집에서는 주인 미니미가 혼자 논다. 한국 시간 저녁 7시~아침 6시는 밤 (창문·가로등 불) |
| 이웃 | 회원이 내 이름으로 남의 방에 들어가면 서로 이웃이 된다 (익명은 안 남는다). 이웃 집이 서로의 동네 골목에 생긴다 |
| 선물 두기 | 아이템을 둘 곳을 직접 고른다: 친구 집 안 바닥, 마당, 우편함(편지처럼 쌓이고 깃발이 선다). 집마다 1개 |
| 방문자 수 | 싸이월드식 `TODAY | TOTAL` (한국 날짜 기준) |
| 공유 | 9:16 스토리 이미지 저장, 링크 복사, 공유 시트 |

## 기술 구성

- Vite + React + TypeScript, 테스트는 Vitest
- 그림은 전부 코드: 방·동네·미니미는 three.js 3D(`src/three`, 모델 파일 없이 코드로 깎는다), 아이콘·아이템 고르기 그림은 `src/art`의 도트 스프라이트
- 3D 코드는 방에 들어갈 때만 불러온다 (첫 화면은 가볍게)
- 백엔드: Supabase (supabase-js) — Auth, Postgres + RLS, Realtime(Presence · Broadcast), Edge Function(웹 푸시)
- 키가 없으면 **테스트 모드**: 이 브라우저 localStorage에 저장하고, 로그인은 탭마다 따로라 한 탭은 방 주인 · 다른 탭은 손님으로 실시간 기능까지 혼자 시험해 볼 수 있다 (BroadcastChannel)
- 아이콘도 이모지 대신 도트 SVG (`src/art/icons.ts`)
- 폰트: [갈무리(Galmuri)](https://github.com/quiple/galmuri) — SIL Open Font License 1.1

```
src/
  art/          미니미·아이템 스프라이트, 방 테마
  lib/          저장소(Supabase/로컬), 좌표, 규칙, 공유 이미지 (단위 테스트 있음)
  components/   화면 (첫 화면 · 대시보드, 로그인, 미니미 만들기, 방 만들기, 방 · 채팅), 방 SVG, 시트
  three/        3D: 미니미 · 가구 · 집 안 · 골목 · 효과 · World(카메라·걷기·문 출입)
supabase/       schema.sql (테이블 · 권한 · RPC 함수), functions/notify (푸시 알림)
public/         sw.js (서비스 워커), manifest, 아이콘, privacy.html
```

## 실행

```bash
npm install
npm run dev      # 비어 있는 포트로 뜸 (기본 5173, 쓰고 있으면 5174, 5175 …)
npm test
npm run build
```

개발 서버 주소 뒤에 `/?gallery` 를 붙여 열면 (예: `http://localhost:5173/?gallery`) 미니미·아이템·방을 한눈에 볼 수 있습니다.

## 배포

[docs/deploy.md](docs/deploy.md)에 Supabase(개인 계정) · 카카오 · 구글 · 푸시 · Cloudflare Pages 순서대로 정리했다. 전부 무료 플랜 안에서 된다.

### 보안 메모

- 방 · 프로필 · 아이템 · 채팅 권한은 RLS: 누구나 읽고, 고치기 · 지우기는 방 주인(`auth.uid()`)만. 아이템 놓기 · 채팅 쓰기 · 방 만들기는 `security definer` 함수로 검사하고 넣는다.
- 손님 "방마다 아이템 1개" 제한과 내보내기는 브라우저 기준의 느슨한 제한이다. 장난 아이템 · 채팅은 방 주인이 치울 수 있다.
