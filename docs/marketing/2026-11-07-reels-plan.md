# 방들이 인스타 릴스 촬영 기획 (2026-11-07)

> 실제 사용 화면을 녹화해 인스타 릴스로 홍보한다. 이 문서는 **찍기 전 설계**다: 무엇을, 왜, 어떻게 찍는지.
> 근거: 서비스 코드 전수 분석 + 2025~2026 릴스·링크형 서비스 바이럴 사례 조사 (출처는 맨 아래).

---

## 1. 한 줄 전략

**"빈 방에 링크 하나 보냈더니 → 친구들이 와서 채워 줬다."**

한국에서 터진 링크형 서비스(내 트리를 꾸며줘 250만 명, 진저호텔, 본디)는 공통적으로 **내 공간은 친구가 채워 줘야 완성**되는 구조였고, "놀러 와서 써 줘"라는 부탁 자체가 스토리 콘텐츠가 됐다. 방들이는 이 구조를 그대로 갖고 있다. 영상은 이걸 보여 주기만 하면 된다.

거기에 방들이만의 차별점 두 개를 얹는다.
- **싸이월드 미니룸 감성**: 2025년 7월 '픽셀 미니미' 열풍(검색량 이틀 만에 3배, 연예인도 참여)으로 지금도 통하는 코드임이 확인됨.
- **실시간으로 같이 논다**: 롤링페이퍼류는 글만 남기고 끝. 방들이는 친구 미니미가 실제로 돌아다니고, 말풍선으로 수다 떨고, 가구를 진짜로 쓴다.

## 2. 알고리즘에 맞춘 원칙 (모든 영상 공통)

| 원칙 | 이유 | 방들이에서 |
|---|---|---|
| **0초에 결과부터** | 첫 1~3초에 이탈 결정. 빈 화면으로 시작 금지 | 첫 프레임은 친구 미니미로 북적이는 방 |
| **DM으로 보내고 싶게** | Mosseri가 꼽은 3대 신호 중 비팔로워 도달에 가장 큰 게 DM 공유. 한국 10대 72.5%가 DM을 제일 많이 씀 | 끝에 "같이 방들이할 친구한테 보내기" |
| **15~30초, 루프** | 끝까지 보기 + 반복 재생이 시청시간을 올림 | 마지막 컷이 첫 컷으로 자연스럽게 이어지게 |
| **소리 없이도 이해** | 대부분 무음으로 봄 | 화면 글자 한 줄 10~15자, 큰 글씨, 아래쪽 20%는 비움(캡션이 가림) |
| **오리지널 오디오** | 비즈니스 계정은 인기곡 못 씀. 오리지널을 우대 | 앱 자체 8비트 BGM·효과음만. 오디오 이름 "방들이 – 하트 뿅뿅" |
| **워터마크 없이** | 다른 플랫폼 재활용물은 덜 노출 | CapCut 내보낼 때 워터마크 끄기 |
| **해시태그 5개 이하** | 2025.12부터 5개 제한. 검색은 캡션·화면 글자 키워드로 | #미니룸 #싸이월드 #방꾸미기 #미니미 #집들이 |
| **훅만 바꿔 테스트** | Trial Reels(비팔로워에게만 먼저 노출, 24시간 지표 확인) | 같은 녹화본에 훅 3~4개 → 이긴 것만 정식 공유 |

### 절대 하지 말 것: 실제 노래 소리

턴테이블로 튼 iTunes 미리듣기를 소리째 녹화해 홍보에 쓰면 **Apple 약관 위반**("영상과 동기화 금지", "다른 서비스 홍보에 사용 금지") + 음원 저작권 침해다. 턴테이블 장면은 **소리를 빼고 8비트 BGM으로 덮고, 곡 제목·앨범 아트는 흐리게** 처리한다.

> ⚠️ 영상과 별개로 확인할 것: Apple 약관에 미리듣기는 "스토어 홍보용, 엔터테인먼트 목적 불가"라는 조항이 있어 **'같이 듣기' 기능 자체**가 걸릴 수 있다. 홍보를 본격적으로 하기 전에 약관을 직접 읽어 보고 판단할 것 (곡 옆 "Apple Music에서 듣기" 링크는 이미 있음).

## 3. 릴스 시리즈 (우선순위 순)

공통: 세로 9:16 (1080×1920), 60fps 원본 → 30fps 내보내기, 오디오는 8비트 BGM + 효과음.

### ① 메인: "링크 하나 보냈더니" (20초) ★ 제일 먼저

| 시간 | 화면 | 화면 글자 |
|---|---|---|
| 0–2초 | 친구 미니미 5~6명이 돌아다니고 말풍선이 오가는 꽉 찬 방 (핑크) | **친구한테 링크 하나 보냈더니** |
| 2–4초 | 컷: 같은 구도의 **텅 빈 방**, 주인 미니미 혼자 | 3시간 전 |
| 4–6초 | 메뉴 → "친구에게 보내기" → 카톡 공유 미리보기 ("○○의 미니룸에 놀러 와!") | 카톡에 이거 하나 보냄 |
| 6–11초 | 현관에 친구 미니미가 하나씩 등장 (빠른 컷), 이름표 | 하나둘 들어오더니 |
| 11–16초 | 아이템이 톡톡 놓임: 케이크, 치즈냥, 하트 풍선… 그리고 **바선생** | 선물 놓고 감 (+ 이상한 것도) |
| 16–19초 | 방명록 펼침, 메모들 | |
| 19–20초 | 다시 꽉 찬 방 (0초 화면과 같은 구도 → 루프) | 너도 방들이 해 봐 · 프로필 링크 |

훅 변형 (Trial Reels A/B):
- A: 친구한테 링크 하나 보냈더니
- B: POV: 2006년 미니홈피인데 친구들이 실시간으로 놀러 옴
- C: 집들이 대신 방들이 함
- D: 빈 방 → 3시간 뒤 (빈 방으로 시작하되 0.5초 만에 전환)

캡션: "내 방 링크 보내면 친구들이 놀러 와서 선물 놓고 가요 🎁 무료·설치 X. 같이 방들이할 친구 태그!"

### ② 킹받는 선물 편 (12초) ★ DM 공유 노림

| 시간 | 화면 | 화면 글자 |
|---|---|---|
| 0–2초 | 친구가 "킹받는거" 탭 열고 바선생 고름 | **친구 방에 몰래 놓고 옴** |
| 2–5초 | 놓을 자리 고르고 메시지 "선물이야 ^^" → 놓고 가기 | |
| 5–9초 | 주인 미니미가 바선생 "잡기" → "바선생이다!!!" 깜짝 놀라 **도망** | 주인 반응 ㅋㅋㅋ |
| 9–12초 | 똥 "건드리기" → 냄새 효과 "으악! 킹받네…" | 이거 놓고 갈 친구 있으면 보내 |

시리즈화 가능: 돌멩이("왜 돌을 주는 거야"), 양말 한 짝, 쓰레기봉투.

### ③ "미니룸인데 진짜 쓸 수 있음" (25초)

| 시간 | 화면 | 화면 글자 |
|---|---|---|
| 0–2초 | 냉장고 누름 → 미니미가 걸어가서 "냉장고 털기" 시트 | **POV: 미니룸 가구가 진짜로 됨** |
| 2–7초 | 재료 칩 계란·라면·김치 톡톡 → 레시피가 걸러짐 → 카드 펼침 | 냉장고 털기 |
| 7–11초 | 전자레인지 → "컵라면은 3분!" → 타이머 시작, 구석에 남은 시간 | 컵라면 타이머 |
| 11–17초 | 달력 → 친구가 "이날 치킨 먹자" 적음 → 주인 화면에 바로 뜸 | 친구가 내 달력에 약속 잡음 |
| 17–21초 | 턴테이블 → 미니미 춤 + 음표 (**무음, 제목 흐림**) | 같이 노래 듣기 |
| 21–25초 | 자명종 → "알람이에요!" 창 | 알람까지 됨 |

### ④ 미니미 만들기 (10초, 루프) — 보는 맛

"아무렇게나" 연타로 미니미가 휙휙 바뀜 → 곰 후드 + 윙크에서 멈춤 → "이 모습으로 시작하기". 화면 글자: **나랑 닮은 미니미 만들기**. 댓글 유도: "너는 어떤 조합?"

### ⑤ 밤하늘 다락방 감성 (15초, 루프) — 저장 노림

밤하늘 테마 + "별 세는 밤" BGM. 미니미가 침대에 누움(불 꺼짐 + Zzz) → 일어나 디스코볼 "파티 타임" → 방 어두워지고 빛 조각. 화면 글자 최소. 캡션: "새벽 감성 미니룸 🌙".

### ⑥ 튜토리얼: 스토리에 내 방 올리는 법 (15초)

가장 큰 확산은 공식 계정이 아니라 **사용자가 자기 스토리에 "놀러 와" 링크를 올리는 것**(NGL·진저호텔 구조). 메뉴 → "스토리 이미지 저장하기" → 인스타 스토리에 이미지 → 링크 스티커에 "링크 복사"한 주소 붙이기. 링크 스티커 문구 예: "내 방 놀러 와 (설치X)".
- 인스타 앱 화면 부분은 **휴대폰으로 직접 녹화**(PC 브라우저로는 못 찍음).

### 캐러셀 (보조, 저장용)

- "킹받는 선물 TOP 5" (바선생·똥·돌멩이·양말·쓰레기봉투 클로즈업)
- "방 테마 3종 + 꾸미기" (핑크 하트방 / 원룸 자취방 / 밤하늘 다락방)

### 게시 순서

1. ① 메인 (훅 4개로 Trial Reels 테스트 → 이긴 버전 정식 공유)
2. ② 킹받는 선물 — ①이 반응 오면 하루이틀 안에 후속으로 (Mosseri: 뜬 콘텐츠는 바로 후속편)
3. ③ 진짜 쓸 수 있음 → ④ → ⑤, 사이사이 ⑥ 튜토리얼
4. 12월: 크리스마스 시즌 (아래 7번)

## 4. 녹화 방법

### 도구 조합

| 역할 | 도구 | 비고 |
|---|---|---|
| 브라우저 조작 | **ego (lite)** + `ego-browser` CLI (이 PC에 설치·Claude Code 스킬 있음) | 클릭·드래그·타이핑을 스크립트로. 사람처럼 보이게 동작 사이 간격·속도 조절 |
| 화면 녹화 | **ffmpeg** (설치됨) `gdigrab` | 창 영역을 60fps로. 9:16로 자르고 1080×1920로 맞춤 |
| 휴대폰 장면 | 사용자 휴대폰 화면 녹화 | 카톡 공유 미리보기, 인스타 스토리 링크 스티커 |
| 편집 | **CapCut** (설치됨) | 컷 편집, 화면 글자, 8비트 BGM, 워터마크 끄기 |

- ego 자체에는 녹화 기능이 없다 → ffmpeg로 녹화.
- ego의 "에이전트 커서 설명 문구(label)"는 **쓰지 않는다** (AI가 조작하는 티가 남). 앱 자체의 탭 표시(링이 오므라드는 효과)로 충분.
- 모바일 화면은 ego에서 CDP로 모바일 뷰포트(390×844, 터치)를 켠다. 820px 이상이면 PC 배치로 바뀌므로 반드시 모바일 폭.
- **사전 테스트 1회 필수**: 5초 테스트 녹화로 화질·fps·뷰포트·글자 선명도 확인 후 본 촬영.

### 여러 명 장면 만드는 법

| 방법 | 장점 | 단점 | 쓰는 곳 |
|---|---|---|---|
| **로컬 모드** (환경 변수 비우고 `npm run dev`) | 같은 브라우저의 탭끼리 실시간 연결 → 혼자서 주인+친구 6명 연출. 아이템 1개 제한 없음. 실제 DB 안 더럽힘 | 알림 안 됨. 로그인 화면에 "테스트 모드" 문구 | ①②③④⑤의 방 안 장면 전부 |
| **실제 배포 사이트** | 진짜 링크·카톡 미리보기 | 손님 1명당 아이템 1개, 탭마다 다른 브라우저 필요 | ①의 카톡 공유 장면, ⑥ |

→ **방 안 장면은 로컬 모드로 찍는다.** 로그인 화면만 피하면 화면상 차이가 없다.

### 촬영용 방 세팅 (로컬 모드)

- 주인: 닉네임 "민트" (예시), 핑크 하트방, 한마디 "내 방에 뭐 하나 놓고 가 줘"
- 친구 6명 (전부 가상 이름): 지윤, 하린, 도윤, 서아, 수상한 고구마(익명), 준
- 미니미는 서로 확실히 다르게 (곰 후드, 캡모자, 리본, 선글라스, 뽀글머리…)
- 아이템 12~15개: 케이크, 치즈냥, 하트 풍선, 몬스테라, 디스코볼, 곰인형, 아아, 치킨 + 킹받는 것 2~3개
- 방명록 메모 예: "집들이 축하해 🎉" / "맨날 라면만 먹는 너에게" / "누군지 맞혀 봐 ㅋ" / "선물이야 ^^ (바선생)"
- 같은 세팅으로 **빈 방 버전**도 하나 (①의 "3시간 전" 컷)

### 촬영 전 체크리스트

- [ ] Windows '애니메이션 효과' 켜기 / 브라우저 동작 줄이기 끄기 (`prefers-reduced-motion`이면 애니메이션 일부 꺼짐)
- [ ] 배경음악 켜기 — 단, 녹화 소리는 쓰지 않고 편집 때 BGM을 따로 깐다 (아래)
- [ ] 알림·메신저 팝업 끄기 (Windows 방해 금지)
- [ ] 주소창이 화면에 안 나오게 (녹화 영역은 페이지만)
- [ ] 실제 이메일·계정 화면이 안 나오게 (카카오·구글 로그인 장면은 찍지 않음)
- [ ] 휴대폰 장면 전: 실제 Supabase가 7일 미사용 일시정지 상태가 아닌지 (한 번 접속해 깨우기)
- [ ] 휴대폰 장면 후: 공개된 방 링크는 "새 링크 만들기"로 바꾸기

### 오디오

- 8비트 BGM 3곡(하트 뿅뿅 / 자취방 오후 / 별 세는 밤)을 **WAV 파일로 뽑아 두고** 편집 때 깐다. (앱 코드로 직접 만든 음악이라 저작권 걱정 없음. 뽑는 스크립트는 촬영 준비 때 만든다.)
- 효과음(타이머 삑삑, 알람 따르릉)도 같은 방식.
- 턴테이블의 실제 노래 소리는 **절대 넣지 않는다.**

## 5. 진행 순서

1. **(지금) 이 기획 확정** — 어떤 릴스부터, 화면 글자 톤 등
2. **촬영 준비** — 로컬 모드 방 세팅, BGM WAV 추출, 녹화 스크립트(ego 조작 + ffmpeg) 작성, 5초 테스트 녹화로 품질 확인
3. **촬영** — 릴스별로 장면 단위 원본 클립 (장면마다 2~3테이크). 결과는 `recordings/` 같은 폴더에 장면 이름으로
4. **휴대폰 장면** — 사용자가 직접: 카톡 공유 미리보기, 인스타 스토리 링크 스티커
5. **편집** — CapCut: 컷, 화면 글자, BGM, 훅 4개 버전
6. **게시** — Trial Reels로 훅 테스트 → 이긴 버전 정식 공유 → 후속편

---

## 6. 영상 밖에서 같이 하면 좋은 것

- **프로필 링크 + UTM**: `bangdeuri.com/?utm_source=ig&utm_content=reel1` 처럼 영상마다 구분해 어느 영상에서 왔는지 측정
- **스토리 링크 스티커**: 공식 계정 스토리에도 같은 링크 반복
- **오리지널 사운드 키우기**: 8비트 BGM을 오디오 이름 붙여 올리면 다른 사람이 그 사운드로 자기 방 영상을 찍을 수 있음 (Locket이 이 방식으로 확산)

## 7. 시즌 기회: 크리스마스 (제일 큰 기회)

내 트리를 꾸며줘·진저호텔 모두 **연말**에 터졌고, 연말 롤링페이퍼는 매년 반복되는 트렌드가 됐다. 공통 장치는 **"메시지는 그날에만 열 수 있음"(공개일 잠금)**.

12월 전에 검토할 기능 아이디어 (영상과 별개, 개발 필요):
- 크리스마스 테마 방 (트리·눈 벽지·선물 상자 아이템)
- 12월 25일에 열리는 방명록 / 선물 상자
- 이 기능이 생기면 "크리스마스까지 내 방 채워 줘" 릴스 시리즈

## 8. 이전 사례에서 배울 점 (본디가 식은 이유)

본디는 1주일 만에 1위를 했지만 느린 로딩, 꾸민 게 날아가는 버그, 금방 바닥나는 아이템 때문에 빠르게 식었다. 홍보로 사람이 몰리기 전에:
- Supabase 무료 한도 확인 (실시간 동시 접속, 7일 일시정지 방지 keepalive 켜져 있는지)
- 아이템을 주기적으로 새로 추가할 계획
