# 동네를 격자 골목으로 + 들어가는 가게들 — 설계

> 2026-11-17 · 동네 확장 (앞 작업: 88667e8 편의점·포장마차·뒷산·바닷가)

## 왜

지금 동네는 큰길 위쪽에 집이 **좌우 한 줄**로만 늘어선다 (`slotX`: 0, −13, +13 …, 집 뒤는 숲으로 막힘).
걸어 다닐 데가 길 하나뿐이라 동네가 좁고 제한적으로 느껴진다. 친구 집이 몇 채 없는 방은 거의 빈 잔디다.

목표는 **동물의숲처럼 돌아다니는 재미가 있는 동네**: 골목이 여러 갈래로 이어지고, 골목마다 들어가 볼 가게가 있고,
같은 동네는 늘 같은 지도라 길을 외워 다닐 수 있다.

## 목표

1. **고정 격자 동네**: 큰길 1 + 뒷골목 2줄 + 남북 샛길로 블록을 만든다. 크기는 친구 수와 상관없이 늘 같다.
2. **가게 자리 고정, 친구 집은 빈 집터에**: 가게 6곳은 늘 같은 자리. 집(내 집 + 친구 16채)은 남은 집터를 가까운 순으로 채운다.
3. **들어갈 수 있는 가게 5곳 추가** (편의점과 같은 방식의 따로 떨어진 공간): PC방 · 코인노래방 · 오락실 · 코인빨래방 · 카페.
4. **밖 장소 3가지 추가**: 붕어빵 노점 · 버스정류장 · 동네 고양이.
5. 뒷산(서쪽 끝) · 바닷가(동쪽 끝) · 공원·놀이터 · 포장마차(큰길 남쪽)는 그대로 살린다.

## 하지 않는 것

- **실제 노래 재생·가사 표시** (저작권: 작곡·작사·음원 권리, 상업 이용 불가). 코인노래방은 화면 연출 + 짧은 효과음만. 오리지널 곡은 나중에.
- 사용자가 집·가게 자리를 옮기거나 땅을 꾸미는 것 (동숲 테라포밍)
- 동네 화폐·코인 경제 (가게 이용은 공짜 연출)
- 버스 타고 다른 동네 가기 (정류장은 앉아서 기다리는 곳 + 지나가는 버스 연출까지)
- 친구 수가 늘면 동네가 커지는 것

## 망하는 경우

- 같은 방 목록인데 사람마다 집 자리가 다르게 나온다 (실시간 좌표가 어긋남)
- 친구 1명 늘었을 때 기존 집들이 다른 자리로 튄다 (길을 외울 수 없다)
- 갈 수 없는 가게·집이 생긴다 (길이 끊김)
- 휴대폰에서 동네가 버벅인다
- 편의점·마당 선물·우편함 같은 지금 되는 것이 깨진다

## 방법 (고른 것)

| 방법 | 내용 | 결과 |
|---|---|---|
| **A. 고정 격자 동네** | 정해진 크기의 블록, 가게 자리 고정, 집은 빈 집터에 | **고름** — 친구 0명이어도 꽉 차 보이고, 늘 같은 지도 |
| B. 지금 줄 + 뒷골목 한 줄 | 덜 고치지만 여전히 좌우로 긴 동네 | 답답함이 반쯤 남아 뺌 |
| C. 친구 수에 따라 블록이 자람 | 친구 추가 때 장소가 이동, 동기화·길 외우기 어려움 | 뺌 |

## 동네 모양

```
 (북)
  ┌뒷산┐ [ 8칸 × 3줄 ]                                         ┌바닷가┐
        줄2: [ ][카페][ ][ ] ┃ [ ][노래방][ ][ ]                 
        ──────── 뒷골목2 ────╋────────────────────
        줄1: [ ][오락실][ ][ ]┃ [ ][ ][빨래방][ ]   🚏(큰길가)
        ──────── 뒷골목1 ────╋────────────────────
        줄0: [편의점][ ][PC방][내집] ┃ [ ][ ][ ][ ]
  ═════════════════ 큰길 (차도·인도·횡단보도) ═══════════════
           포장마차 · 공원 · 놀이터 · 붕어빵 노점
 (남)
```
(가게 칸 자리는 예시, 최종 자리는 구현 때 보기 좋게 정한다 — 단, 한 번 정하면 고정)

- **집터(칸)**: 8열 × 3줄 = 24칸. 가게 6칸(편의점 포함) + 집 18칸 ≥ 17채. 칸 크기는 지금 `LOT_W=13` 그대로.
- **모든 줄은 남쪽 길을 바라본다** (줄0 → 큰길, 줄1 → 뒷골목1, 줄2 → 뒷골목2). 집·가게는 지금처럼 문이 남쪽이라 3D 회전이 필요 없다. 집 뒤는 다음 길과 맞닿는다.
- **뒷골목**: 차 없는 골목길 (폭 약 4m, 인도 구분 없음, 가로등·화분·전봇대). 큰길만 차도·인도·횡단보도.
- **샛길(남북)**: 가운데 1개(x=0 근처, 횡단보도와 이어짐) + 양쪽 1개씩, 줄을 가로질러 모든 골목을 잇는다. 샛길 자리만큼 칸 사이가 벌어진다.
- **뒷산**은 격자 서쪽, **바닷가**는 동쪽에 붙는다. 이제 동네 폭이 고정이라 위치도 고정.
- **내 집**: 줄0 가운데 칸 (지금처럼 대문 앞이 손님 첫 자리 `guestSpot`).
- **친구 집 배치**: 집 칸 목록을 "내 집에서 가까운 순" 고정 순서로 정해 두고, 친구를 지금처럼 `createdAt, id` 순으로 차례로 넣는다. 친구가 늘면 뒤 칸만 새로 찬다 → 기존 집은 안 움직인다. 친구가 빠지면 그 뒤 순서 집들이 한 칸씩 당겨진다 (사용자 결정: 드문 일이라 괜찮음). 칸은 서버에 저장하지 않고 방 목록만으로 화면에서 계산한다.
- **빈 집터**: 잔디 + "입주 대기" 팻말 (누르면 "친구를 초대하면 여기 집이 생겨요" + 초대 링크로). 작은 텃밭·벤치로 꾸며 휑하지 않게.

## 가게 (들어가는 곳)

편의점과 같은 구조: 골목 건물 문을 누르면 따로 떨어진 공간으로 들어가고, 안의 물건을 누르면 미니미가 가서 동작 + 효과 + 한마디. 같은 가게 안 사람끼리 실시간으로 보인다.

| 가게 | 안에 있는 것 (누르면) | NPC |
|---|---|---|
| PC방 | PC 좌석 6~8개 (앉아서 게임 · 화면 효과, 옆자리 친구와 나란히), 카운터 라면·음료 주문, 정수기 | 알바생 |
| 코인노래방 | 부스 2~3개: 마이크 잡고 노래(가짜 곡 제목 화면 · 조명 · 점수 "100점!"), 탬버린, 소파 앉기 | 사장님 |
| 오락실 | 인형뽑기 (가끔 성공 연출), 펀치기 (점수), 리듬게임, 레이싱 의자, 동전교환기 | — |
| 코인빨래방 | 세탁기 돌리기 (빙글 효과), 건조기, 의자 앉아 기다리기, 세제 자판기 | — |
| 카페 | 주문 카운터, 테이블·창가 자리 앉기, 디저트 진열장 | 바리스타 |

## 밖 장소

- **붕어빵 노점**: 큰길 남쪽 인도·공원 쪽. 서서 사 먹기 (김 효과). 포장마차처럼 작은 수레.
- **버스정류장**: 큰길가. 벤치 앉기, 가끔 버스가 지나가며 잠깐 멈췄다 간다 (탈 수는 없음). 버스 시각은 시계로 정해 모든 화면에서 같게.
- **동네 고양이**: 1~2마리가 골목을 어슬렁. 움직임은 **시각(분 단위) + 고정 씨앗**으로 계산해 네트워크 없이 모든 화면에서 같은 자리. 누르면 쓰다듬기 (하트 효과, 고양이 "냐~"). 가끔 집 앞 담 위·정류장 벤치에서 낮잠.

## 지금 되는 것과의 관계 (깨지면 안 됨)

- `AreaId`: `'cvs'`는 그대로 둔다 (옛 화면과 실시간 호환). 새 가게는 `'pc' | 'sing' | 'arcade' | 'laundry' | 'cafe'`. `isArea`가 다 받는다.
- 마당 선물·우편함·`yardToTown`·`lotAtYard`는 `Lot`에 줄 정보만 더해 그대로 동작.
- 동네 지도 메뉴(`TOWN_PLACES`)에 새 가게·정류장을 추가해 바로 가기.
- 손님 첫 자리는 그대로 (방 주인 대문 앞 인도).
- **옛 버전과 새 버전이 한 방에 섞이는 건 지원하지 않는다** (설계자 판단: 웹앱이라 새로고침하면 새 버전). 실시간 메시지에 버전 표시나 맞추기 처리는 하지 않는다. `'cvs'` 이름을 그대로 두는 건 고칠 곳을 줄이려는 것일 뿐이다.
- 공원 놀이터 자리 키(`park/종류번호:자리`)는 **이름 형식만** 유지하고, 번호는 새 배치에서 새로 매겨도 된다 (설계자 판단, 위와 같은 이유).

## 진행 순서 (권장)

1. 격자 배치 데이터 + 막힘 + 길찾기 + 테스트 (화면은 아직 옛 3D여도 됨)
2. 3D: 골목·샛길·줄별 집·빈 집터
3. 가게 목록으로 편의점 옮기기 (동작 그대로인지 확인)
4. 가게 5곳 하나씩 (PC방 → 노래방 → 오락실 → 빨래방 → 카페)
5. 붕어빵 · 정류장 · 고양이

## 만드는 사람에게 맡기는 것

- 칸·길 정확한 치수, 샛길 위치, 가게가 어느 칸인지 (위 예시는 참고, 정하면 고정)
- 가게 안 배치와 물건 개수, 한마디 문구, 효과 종류
- 뒷골목 꾸밈 (가로등·화분·전봇대·담벼락 낙서 등)
- 카메라 기본 거리·각도 (동네가 깊어진 만큼 조정)
- 휴대폰 성능 대책 (멀리 있는 줄은 그림자 끄기, 같은 모양 합치기 등)
