# 오브젝트를 진짜로 쓰기 — 설계

> 2026-11-03 · 방들이 개선 2번 (1·4·5번 배경음악·두 손가락 회전·놀러 간 방은 이미 끝남)

## 왜

지금 가구를 누르면 미니미가 가서 동작하고 한마디 하는 게 전부다. 금방 질린다.
현실에서 쓰듯이 **진짜로 쓸 수 있으면** 방에 자주 들어올 이유가 생기고, 친구랑 같이 쓸 이유(같이 듣기, 약속 잡기)가 생긴다.

## 목표 (이번 1차)

1. **시계 → 알람**: 방 주인만 맞춘다. 정해진 시각에 앱이 열려 있으면 방에서 따르릉, 닫혀 있으면 푸시 알림.
2. **달력 (새 가구) → 일정 공유**: 주인은 내 일정을 쓰고, 친구(익명 손님 포함)도 주인 방에 와서 약속을 적는다.
3. **턴테이블 (새 가구) → 노래 같이 듣기**: iTunes 검색 → 30초 미리듣기. 같은 방에 있는 사람들이 같이 듣는다.
4. **조리대·냉장고 → 레시피**: 앱에 직접 넣은 자취 요리 레시피 카드.
5. **책상·전자레인지·세탁기 → 타이머**: 뽀모도로, 컵라면 3분, 빨래.

## 하지 않는 것

- 휴대폰 기본 알람 앱에 알람 넣기 (웹앱은 못 한다. 안드로이드 intent 꼼수는 기기마다 달라 안 한다)
- 노래 전곡 재생, 다른 음원 서비스 (Jamendo 등)
- 레시피 외부 API (식약처 등) — 나중에
- 2차로 미룬 아이디어: TV 유튜브 같이 보기, 냉장고 메모 자석, 책장 추천 책, 스탠드 밤 모드, 화분 키우기, 전화기 콕 찌르기, 케이크 생일 카운트다운, 트로피 순위

## 망하는 경우 (이렇게 되면 실패)

- 친구가 주인 알람을 건드릴 수 있다
- 익명 장난 일정을 주인이 못 지운다
- 턴테이블 노래와 배경음악이 겹쳐 시끄럽다
- 가구를 누를 때마다 창이 떠서 원래 있던 "미니미가 가서 노는" 재미가 사라진다

## 사용자가 정한 것

| 항목 | 결정 |
|---|---|
| 알람 | 방에서 울림 + 앱이 닫혀 있으면 푸시 (서버 예약 필요) |
| 달력 쓰기 | 익명 손님도 쓸 수 있다 (친구는 로그인 없이 링크로 들어오므로) |
| 노래 | iTunes 검색 30초 미리듣기 |
| 레시피 | 앱에 직접 넣은 카드 |

## 공통: 가구를 "쓰는" 방법

- 지금처럼 가구를 누르면 미니미가 걸어가서 동작한다. **도착하면** 그 가구의 도구 창(아래에서 올라오는 시트, 기존 `Sheet`)이 열린다.
- 도구가 있는 가구는 누르기 전에 알 수 있게 작은 표시(반짝이·아이콘)를 단다 — 모양은 만드는 사람이 정한다.
- 도구 창을 닫으면 미니미는 하던 동작을 이어 간다.
- 방 주인 전용 기능을 손님이 열면 읽기 전용 화면 + "방 주인만 맞출 수 있어요" 안내.

## 1. 시계 알람

- 알람은 안방에 늘 있는 **탁상시계 가구**(`fx-alarm`)에 단다. 벽에 붙이는 시계 스티커(꾸미기)는 그대로 장식이다.
- 방 주인만 만들기·고치기·끄기·지우기. 손님은 지금 시각만 보인다 (주인 알람 시각은 안 보인다).
- 알람 하나 = 시각(HH:MM) + 요일(없으면 한 번만) + 문구(20자) + 켜짐 여부. 방 하나에 최대 10개.
- 시간대는 한국 시간(KST) 고정 (서비스 대상이 한국, 기존 `kstDate`와 같음).
- 알람은 주인 계정에 딸린다. 앱 전체에서 로그인한 내 알람을 불러 두고, 앱이 열려 있으면 (첫 화면·친구 방 등 어느 화면이든, 탭이 여러 개면 각각) 그 시각에 방 시계처럼 따르릉 효과음 + 큰 알림 창 + "5분 뒤 다시". 배경음악은 그동안 멈춘다.
- 앱이 닫혀 있으면 서버가 푸시를 보낸다. 주인이 알림을 켜 둔 기기로 간다 (기존 `push_subscriptions` 재사용, 새 종류 `alarm`, 알림 설정에 '알람' 스위치 추가 — 기본 켜짐).
- 이 기기에서 푸시를 못 받는 상태(꺼짐·미지원·아이폰 홈 화면 미설치)면 알람 창에 "앱을 닫으면 안 울려요" 안내와 알림 켜기 버튼을 보여 준다.
- 서버: `alarms` 테이블 + 다음 울릴 시각 `next_at`. Supabase `pg_cron`이 1분마다 Edge Function `alarm`을 부르고, 함수가 `next_at <= now()`인 알람에 푸시를 보내고 `next_at`을 다시 계산한다(한 번짜리는 꺼진다). 함수는 비밀 헤더로만 부를 수 있게 한다.
- 앱이 열려 있을 때와 푸시가 둘 다 오는 건 괜찮다 (푸시 클릭하면 앱이 열릴 뿐).
- 로컬 모드: 서버 예약 없이 앱이 열려 있을 때만 울린다.

## 2. 달력

- 새 가구 `calendar`(벽걸이 달력 도트 그림)를 거실 벽 쪽에 둔다.
- 월 보기 + 날짜를 누르면 그날 일정 목록 + 쓰기.
- 일정 = 날짜 + 시각(선택) + 내용(40자) + 쓴 사람 이름. 주인 일정과 친구 일정은 색으로 구분한다.
- 누구나 쓸 수 있다 (로그인한 친구는 닉네임, 익명 손님은 익명 이름).
- 주인은 **나만 보기** 일정을 쓸 수 있다. 나만 보기 일정은 다른 사람에게 안 보인다 (서버에서 막는다).
- 다른 일정은 방 링크를 아는 사람에게 보인다 (방명록·채팅과 같은 공개 범위).
- 지우기: 주인은 아무 일정이나. 쓴 사람은 자기 일정만.
  - 내 미니미(회원 닉네임)로 쓴 일정: 계정으로 확인.
  - 익명으로 쓴 일정 (회원이 정체를 숨긴 경우 포함): 그 기기에 저장한 비밀 키로 확인. 회원이 익명으로 쓰면 계정 id를 저장하지 않는다 (주인이 정체를 알 수 없게).
  - 계정 id·비밀 키 컬럼은 다른 사람이 읽을 수 없다 (컬럼 권한).
  - 1분 5개 제한은 계정 또는 기기 키 기준.
- 도배 막기: 방 하나에 앞으로 있을 일정 최대 200개, 같은 사람이 1분에 5개까지.
- 친구가 일정을 쓰면 주인에게 푸시 (새 종류 `event`, 알림 설정에 스위치 추가).
- 같은 방에 있는 사람들 화면은 실시간으로 갱신 (기존 방 채널에 신호 하나 추가).

## 3. 턴테이블

- 새 가구 `turntable`(도트 그림)을 거실에 둔다. 누르면 미니미가 가서 고개를 까딱이고 도구 창이 열린다.
- 검색: iTunes Search API (`country=KR`, `entity=song`), 키 없음. 결과마다 앨범 아트, 곡명, 가수, 재생 버튼.
- Apple 규칙: 앨범 아트와 "Apple Music에서 듣기" 링크(`trackViewUrl`)를 같이 보여 준다. 미리듣기 파일은 저장하지 않고 Apple 주소에서 바로 튼다.
- 누구나 노래를 틀 수 있다. 틀면 같은 방에 지금 있는 사람 모두에게 같은 곡이 같은 위치부터 나온다 (실시간 채널). 나중에 튼 사람이 이긴다. "OO님이 튼 노래" 표시.
- 브라우저가 자동 재생을 막으면 (아이폰 등) "OO님이 노래를 틀었어요 — 눌러서 같이 듣기" 버튼을 띄운다.
- 30초 끝나면 멈춘다. 각자 내 화면에서만 끄기(음소거)도 된다.
- 노래가 나오는 동안 배경음악은 멈추고 (`bgm.hold`), 끝나면 다시 나온다.
- 지금 나오는 곡은 저장하지 않는다 (방에 있을 때만의 일).

## 4. 레시피

- 자취 요리 20개 정도를 코드에 넣는다: 이름, 걸리는 시간, 난이도, 재료, 순서(짧게), 태그(라면·밥·야식·간단 등).
- 조리대: 레시피 목록 → 카드 보기. 카드에서 "타이머 맞추기"(걸리는 시간)로 타이머와 이어진다.
- 냉장고: "냉장고 털기" — 있는 재료를 고르면 그 재료로 되는 레시피만 보인다.

## 5. 타이머

- 책상: 뽀모도로 25분 집중 / 5분 휴식 반복.
- 전자레인지: 1·2·3분 빠른 버튼 (컵라면 3분).
- 세탁기: 40분 기본, 직접 바꿀 수 있다.
- 내 기기에서만 도는 타이머다. 앱이 열려 있을 때 끝나면 그 가구에서 효과 + 알림 창. 닫혀 있을 때는 이번엔 안 울린다.
- 돌고 있는 타이머는 화면 구석에 작게 남은 시간 표시.

## 제약

- 기존 구조 유지: Vite + React + TS, Supabase는 RPC(`security definer`) 쓰기 + RLS 읽기, `Backend` 인터페이스에 local·supabase 둘 다 구현.
- 새 SQL은 `supabase/schema.sql`에 이어 붙이고, 이미 배포된 DB에 돌릴 수 있게 `create ... if not exists` / `create or replace` 로 쓴다. `docs/deploy.md`에 돌리는 법(SQL, pg_cron·pg_net 켜기, `alarm` 함수 배포, 비밀값)을 적는다.
- 새 그림(달력·턴테이블)은 기존처럼 문자열 격자 도트 스프라이트.
- 순수 로직(다음 알람 시각, 레시피 거르기, 타이머, 달력 날짜 계산)은 테스트를 단다.
- 작업 단위마다 커밋한다 (사용자가 이번 작업에 자동 커밋을 직접 요청함).

## 만드는 사람이 정할 것

- 도구 창 생김새, 가구에 다는 표시, 새 가구 자리·그림
- 레시피 목록 내용
- 실시간 신호 이름과 모양, 새로 들어온 사람에게 지금 나오는 곡을 알려줄지
- iTunes가 브라우저에서 바로 안 불리면(CORS) Cloudflare Pages 함수로 대신 부르기
- 알람 울림 소리 (Web Audio로 만든다)

## 내가 정한 것 (사용자 확인 필요)

- 익명 손님 일정 지우기는 기기 비밀 키로
- 타이머는 이번엔 앱이 열려 있을 때만
- 턴테이블은 누구나 틀 수 있고 마지막에 튼 사람이 이김
- 알람 최대 10개, 일정 최대 200개
- 알람은 안방 탁상시계에, 앱 어느 화면에서든 울림
- 회원이 익명으로 쓴 일정은 계정을 남기지 않음
- 알람 푸시 스위치 추가 (기본 켜짐), 푸시 못 받는 기기엔 안내
