# 아트 리뉴얼 — 도형 디오라마에서 "게임 같은" 그림체로

> 2026-11-21 · dev 브랜치

## 왜

캐릭터·가구·건물이 전부 코드로 깎은 구·원기둥이라 "AI로 대충 만든 서비스"처럼 보인다. 게임 캐릭터·오브젝트처럼 디자인된 느낌으로 바꾼다.

## 정한 방향

- **하우스 스타일 = Kenney식 각진 로우폴리 + 툰 명암 + 외곽선.** 색은 공용 팔레트에서 고른다.
- **흔한 물건은 CC0 에셋(Kenney), 한국 동네 전용 물건은 Blender로 직접 만든다.** PC방·노래방·오락실·포차·붕어빵 수레·편의점처럼 에셋 팩에 없는 것이 계속 늘어나기 때문.
- **Blender는 스크립트로 돌린다** (`tools/blender/`, `blender --background --python`). 모든 모델은 같은 팔레트·비율 규칙을 쓰는 공용 헬퍼로 만든다 → 그림체가 유지된다. 결과물은 `public/models/*.glb`로 커밋한다.
- **바꿔치기는 조금씩, 깨지지 않게.** GLB는 앱 시작 때 미리 불러 두고, 빌더(`buildItem3D`, 가게 인테리어 등)는 모델이 있으면 모델을, 없으면 지금 코드 모양을 쓴다. 자리·앉는 높이·상호작용 좌표는 그대로 둔다.

## 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 전체 툰 셰이딩 + 외곽선 (`kit.ts` `toon()`/`mat()` + 렌더 루프). 느린 기기는 외곽선 자동 끔 | 완료 |
| 2 | GLB 파이프라인: `src/three/models.ts` (미리 불러오기, 동기 복제, 없으면 대체, 팔레트 이름으로 다시 칠하기) | 완료 |
| 3 | Blender 툴체인(`tools/blender/lib.py`) + PC방 의자·모니터·본체·키보드 (`pc_bang.py`) | 완료 |
| 4 | 미니미: 지금 뼈대(관절 그룹·자세 애니메이션)는 두고 몸·머리·옷·모자 메시를 Blender 파츠로 교체 | 다음 |
| 5 | 방 가구 (`furniture3d.ts`의 가구부터), 손님이 놓는 아이템 | 다음 |
| 6 | 동네 건물·길·소품 (`town3d.ts`, `places3d.ts`) | 다음 |
| 7 | 나머지 가게 (카페·노래방·오락실·빨래방·편의점) | 다음 |

## 망하는 경우

- 휴대폰에서 프레임이 떨어진다 (외곽선은 장면을 한 번 더 그린다) → `__bdWorld.bench()`로 전후 비교, 무거우면 저사양에서 외곽선 끔
- 모델 크기가 달라져 미니미가 의자에 떠서 앉거나 가구를 뚫는다 → 모델은 기존 가구 크기(bbox)에 맞춰 만든다
- GLB 로딩이 늦어 첫 화면이 빈다 → 로딩 전에는 지금 코드 모양으로 보인다
