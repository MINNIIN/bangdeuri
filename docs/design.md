# 방들이 기획·설계 문서

> 2026-10-25 '방문록'에서 '방들이'(집들이 → 방들이)로 이름을 바꿨다. 같은 이름의 앱이 이미 앱스토어에 있어서 검색·상표가 겹치기 때문. 아래 본문의 '방문록'은 당시 이름이다.

> 작성일: 2026-10-24 · 떠오르는대로 서비스만들어보기 2탄

## 1. 한 줄 정의

**"내 방은 친구들이 채워줘."**
미니미(캐릭터)와 빈 방을 고르고 링크를 스토리에 올리면, 들어온 친구들이 아이템을 하나씩 놓고 한 줄을 남기고 간다.
방이 채워질수록 *친구들 눈에 비친 나*가 된다. 싸이월드 미니룸 + 방명록 + 롤링페이퍼.

## 2. 왜 만드나

- 싸이월드 미니룸·미니미처럼 "내 공간을 꾸미는" 재미는 사라졌지만 Y2K 감성은 다시 돌아오고 있다.
- 그런데 혼자 방을 꾸미기만 하면 금방 질리고, 자랑할 거리가 없다.
- 그래서 **꾸미는 손을 친구에게 넘긴다.** 친구가 와야 방이 채워지니 공유할 이유가 생기고, 친구가 놓고 간 물건이 나에 대한 한마디가 된다. ("맨날 라면 먹으니까 라면 냄비 놓고 감")
- 크리스마스 트리 꾸며주기·롤링페이퍼처럼 이미 검증된 "링크 받아서 채워주기" 구조다.

## 3. 타깃 & 톤

- 인스타 스토리·릴스를 일상적으로 쓰는 10대 후반~20대, 지인끼리
- 톤: 싸이월드 미니홈피의 Y2K 픽셀 감성. 귀엽고 정겹게. 도트 폰트(갈무리), 도트 아이템, `Today | Total` 방문자 카운터
- 결제 없음, 회원가입 없음

## 4. 핵심 흐름

### 방 주인
1. 미니미 3종 중 하나 고르기 (단발 · 캡모자 · 곰돌이)
2. 방 3종 중 하나 고르기 (핑크 하트방 · 원룸 자취방 · 밤하늘 다락방)
3. 이름(8자)과 오늘의 한마디(30자) 쓰기 → 방 생성
4. 스토리용 9:16 이미지 저장 + 링크 복사 → 스토리에 올리고 링크 스티커 붙이기
5. 친구들이 놓고 간 아이템을 누르면 그 위에 말풍선으로 누가 어떤 말을 남겼는지 뜬다. 마음에 안 드는 건 치울 수 있다
   - 방명록은 "방명록 보기" 창에서 5개씩 페이지로 넘겨 본다. 항목을 누르면 방에서 그 아이템에 말풍선이 뜬다
   - "친구 입장으로 보기"로 친구 화면을 확인하면서 직접 아이템을 놓아 볼 수 있다
6. 방이 채워지면 다시 스토리로 자랑

### 방문자(친구)
1. 링크로 들어온다 (방문자 수 +1)
2. "아이템 놓고 가기" → 아이템 18종 중 하나 고르기
3. 방 바닥을 눌러 놓을 자리 정하기 (다시 누르면 옮겨짐)
4. 닉네임(8자) + 한마디(40자) → 놓고 가기. **놓자마자 방에 바로 보인다**
5. "나도 내 방 만들기"로 이어진다 (바이럴 루프)

## 5. 규칙

| 항목 | 값 |
|---|---|
| 한 방에 놓을 수 있는 아이템 | 최대 40개 (꽉 차면 방 주인이 정리해야 더 놓을 수 있음) |
| 방문자 한 명이 놓는 개수 | 방마다 1개 (기기 기준, 느슨한 제한). 로컬 모드에서는 테스트용으로 제한 없음 |
| 방 회전 | 좌우로 끌면 ±30° 안에서만 살짝 돌아간다 (한도 끝에서는 고무줄처럼 버티다 돌아옴). 면이 바뀌는 회전은 아님 |
| 방 주인 확인 | 로그인 없음. 방 만들 때 받은 비밀 키를 그 브라우저에 저장. 그 기기에서만 아이템 삭제·한마디 수정 가능 |
| 방문자 수 | Today(한국 날짜 기준) / Total. 방 주인 본인 방문과 같은 탭 새로고침은 세지 않음 |
| 공개 범위 | 링크를 아는 사람은 누구나 방과 메시지를 볼 수 있음 |

## 6. 하지 않는 것 (MVP 범위 밖)

- 결제, 유료 아이템
- 로그인, 팔로우, 피드, 실시간 채팅
- 방 주인이 직접 아이템을 놓는 기능 (방은 친구가 채운다는 컨셉을 지킨다)
- 아이템 회전·크기 조절

## 7. 기술 구성

- Vite + React + TypeScript, 테스트는 Vitest (mucha와 같음)
- 그림은 전부 코드: 미니미·아이템은 문자열 격자로 그린 도트 스프라이트를 SVG `rect`로 렌더링, 방은 아이소메트릭 SVG
- 저장소: **Supabase 무료 플랜** (PostgREST를 `fetch`로 직접 호출, SDK 없음)
  - 쓰기는 전부 RPC 함수(`security definer`)로만. 테이블 직접 쓰기 권한 없음
  - `owner_secret` 컬럼은 익명 사용자가 읽을 수 없음 (컬럼 단위 권한)
- 키가 없으면 **로컬 모드**: 같은 브라우저 localStorage에 가짜 DB를 만들어 전체 흐름을 혼자 테스트할 수 있음
- 공유 이미지: 방 SVG를 canvas에 그려 1080×1920 PNG 생성

## 8. 아이소메트릭 좌표

바닥은 마름모. 아이템 위치는 바닥 좌표 `(u, v)` ∈ [0, 1]로 저장한다 (회전과 무관한 방 기준 좌표).
화면에 그릴 때는 방 가운데를 축으로 θ만큼 돌린 뒤 `x = 170 + 160·(u − v)`, `y = 125 + 80·(u + v)` (SVG viewBox 340×300).
그리는 순서는 돌린 좌표의 `u + v`가 작은(뒤쪽) 것부터. 벽 네 개 중 가운데보다 뒤에 있는 벽만 그린다.

> 최종 방향 메모: 사용자는 3D 쿼터뷰(three.js) + 드래그 회전을 원함. 이 2D 도트판으로 먼저 확인한 뒤 3D 전환 여부를 정한다.

## 9. 2차: 방 꾸미기 · 오브젝트 확장 · 미니미 이동 (2026-10-25)

역할 나누기: **방 주인은 꾸미기 툴로 벽·바닥을 꾸미고, 친구들은 방 안에 가구·오브젝트를 놓는다.**
친구는 진짜 살림을 채워 주는 쪽(가전·가구)으로도, 장난치는 쪽(킹받는거)으로도 놓을 수 있다.

### 방 꾸미기 (방 주인만)
- 벽지: 무늬 9종 × 색 12색. 왼쪽 벽 / 오른쪽 벽 / 양쪽 다
- 그림: 벽을 정면으로 펼친 40×28 도트 격자에 12색 펜·지우개로 그린다 (누른 채 끌면 이어서 칠함)
- 장식: 창문·액자·달력·전구줄·벽시계·선반·포스터·거울 등 10종. 벽마다 5개까지, 끌어서 옮기고 눌러서 떼기
- 바닥: 무늬 6종 × 색 12색
- 되돌리기(최근 30번), 저장 전까지는 미리보기만
- 저장 형식: `rooms.decor` (jsonb). 읽을 때 `normalizeDecor`로 색·무늬·그림·장식 위치를 검사하고 이상하면 테마 기본값으로 바꾼다. 서버는 크기(16KB)와 방 주인 키만 검사

### 오브젝트
- 42종, 카테고리 탭: 가구 · 가전 · 소품 · 먹을거 · 킹받는거
- 방 하나에 최대 60개 (40 → 60)

### 미니미 이동
- 빈 바닥 탭/클릭, PC 우클릭 → 그 자리로 걸어감 (보는 사람 화면에서만 움직이고 저장하지 않음)
- 좌우로 6px 넘게 끌면 회전, 그보다 적게 움직이고 떼면 탭이라 회전과 겹치지 않는다
- three.js는 쓰지 않음 (3D 전환 때 같이 검토)
